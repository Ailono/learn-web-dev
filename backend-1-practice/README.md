# Backend. Задание 1 — класс Appointment

Решение задания 1: запись клиента вынесена в класс `Appointment`, а `create_appointment()` возвращает объект этого класса только при корректных данных.

## Запуск

```bash
python appointment.py
```

## Правила

- все поля записи должны быть заполнены;
- мастер и услуга должны существовать в справочниках;
- время указывается в формате `HH:MM` и должно входить в часы работы салона — с `08:00` до `20:00`;
- на одно время нельзя создать две записи (действующее ограничение салона);
- при нарушении любого правила `create_appointment()` возвращает `None`, а список `appointments` не меняется.

## Файлы

- `appointment.py` — классы `Master`, `Service`, `Appointment`, функция `create_appointment()` и демонстрация проверок.

## Пример вывода

```text
Список записей:
Иванова А.А. 10:00
Петрова А.А. 11:00

Попытка с пустым именем: None
Количество записей: 0

Попытка записать на 00:00: None
Количество записей: 0

Попытка записать на занятое время: None
Количество записей: 1
```
