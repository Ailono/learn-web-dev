# Лезвие — выбор даты и времени на React

Практическая работа №3: страница «Выбор даты и времени» из предыдущих заданий, переведённая на React и Vite. Функциональность осталась прежней — изменился только способ реализации: JSX, компоненты, `useState` и обработчики `onClick`.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

Сборка production-версии:

```bash
npm run build
npm run preview
```

## Структура проекта

- `index.html` — HTML-обёртка Vite с корневым элементом `#root`;
- `vite.config.js` — конфигурация Vite с плагином React;
- `src/main.jsx` — точка входа, подключение стилей и рендер приложения;
- `src/index.css` — базовый сброс стилей и CSS-переменные;
- `src/styles/booking.css` — стили страницы, перенесённые из второй практики;
- `src/App.jsx` — корневой компонент;
- `src/screens/BookingScreen.jsx` — состояние страницы и обработчики;
- `src/components/` — компоненты шапки, подвала, календаря, слотов и нижней панели;
- `src/data/date.js` — чистые функции и константы для работы с датами;
- `src/data/slots.js` — данные слотов и функция занятости времени.

## Что работает

- при открытии страницы сразу выбран доступный день и показаны его слоты;
- клик по дню выбирает дату, обновляет слоты и сбрасывает выбранное время;
- клик по слоту выбирает время и обновляет нижнюю панель;
- кнопки «‹» и «›» листают месяцы назад и вперёд;
- прошедшие дни приглушены и недоступны для выбора;
- занятые слоты зачёркнуты и не кликаются;
- нижняя панель показывает день недели, число, месяц, год и выбранное время;
- кнопка «Продолжить» активна только после выбора времени;
- вёрстка адаптируется под планшеты и телефоны.

## Как устроено

Состояние хранится в `BookingScreen` через `useState`: текущий месяц и год, выбранный день, выбранное время и слоты. Календарь и слоты рендерятся через `.map()` с `key`. Обработчики передаются в компоненты пропсами и вызываются через `onClick` — без `addEventListener` и ручной сборки HTML.

Чистые функции `buildCalendarGrid`, `compareDates`, `isDateSelectable` и массивы месяцев/дней недели находятся в `src/data/date.js` и не зависят от React.
