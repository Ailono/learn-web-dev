# Лезвие — выбор даты и времени

Практическая работа №2: интерактивная страница «Выбор даты и времени» для записи в барбершоп, оживлённая на нативном JavaScript.

## Что внутри

- `index.html` — разметка страницы, контейнеры для динамического календаря и слотов;
- `styles.css` — стили, адаптивность и состояния интерактивных элементов;
- `script.js` — вся логика выбора даты и времени на нативном JavaScript;
- `images/` — папка для изображений (сейчас страница собрана без растровых картинок, иконки встроены SVG).

## Как открыть

1. Откройте `index.html` двойным кликом — страница откроется в браузере.
2. Или запустите Live Server в VS Code: правый клик по `index.html` → **Open with Live Server**.

## Что реализовано

- календарь строится в JavaScript и показывает текущий месяц;
- при открытии страницы сразу выбран доступный день и показаны его слоты;
- клик по дню выбирает дату и обновляет список свободного времени, ранее выбранное время сбрасывается;
- клик по слоту выбирает время и обновляет нижнюю панель;
- кнопки «‹» и «›» листают месяцы назад и вперёд;
- прошедшие дни выглядят приглушённо и не кликаются;
- занятые слоты зачёркнуты и недоступны для выбора;
- нижняя панель показывает день недели, число, месяц, год и выбранное время;
- кнопка «Продолжить» активируется только после выбора времени;
- после каждой перерисовки обработчики на новые ячейки и слоты навешиваются заново;
- адаптивная вёрстка для планшетов и телефонов.

## Структура скрипта

`script.js` разделён на части: данные, состояние, чистые функции (`buildCalendarGrid`, `compareDates`, `isDateSelectable`), рендер календаря и слотов, обновление нижней панели и навигации, обработчики и инициализация через `DOMContentLoaded`.
