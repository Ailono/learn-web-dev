# Лезвие — выбор даты и времени с имитационным сервером

Практическая работа №4: страница «Выбор даты и времени» из предыдущих заданий получает данные с имитационного сервера. Логика страницы не изменилась — «сегодня» и слоты теперь приходят через `fetch`, а во время запросов показываются заглушки загрузки и сообщения об ошибках.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Сборка production-версии и её просмотр:

```bash
npm run build
npm run preview
```

Имитационный сервер работает и в dev-, и в preview-режиме на порту `3000`.

## Структура проекта

- `index.html` — HTML-обёртка Vite;
- `vite.config.js` — плагин React и подключение имитационного API;
- `server/database.js` — «база данных»: сегодняшняя дата, наборы слотов для будней и выходных, полностью занятые даты;
- `server/server.js` — плагин Vite, который перехватывает запросы `/api/*` и отдаёт JSON с задержкой `DELAY_MS` (600 мс);
- `src/main.jsx` — точка входа;
- `src/index.css` — базовый сброс стилей и CSS-переменные;
- `src/styles/booking.css` — стили страницы и состояния загрузки/ошибки;
- `src/api.js` — клиент запросов `fetchToday()` и `fetchSlots(date)`;
- `src/App.jsx` — корневой компонент;
- `src/screens/BookingScreen.jsx` — состояние страницы, `useEffect` с запросами и защита от гонок;
- `src/components/` — шапка, подвал, календарь, дни, слоты, итоговая панель и панель состояния календаря;
- `src/data/date.js` — чистые функции и константы для работы с датами;
- `src/data/slots.js` — группировка слотов по времени суток.

## Эндпоинты

| Метод | URL | Ответ |
| --- | --- | --- |
| GET | `/api/booking/today` | `{ day, month, year }` — «сегодня» |
| GET | `/api/slots?day=&month=&year=` | `{ date, slots }` — слоты на дату |

`month` — 0-индексный: `0` — январь, `10` — ноябрь. Каждый слот имеет вид `{ time, available }`.

Проверить эндпоинты можно прямо в браузере:

- `http://localhost:3000/api/booking/today`
- `http://localhost:3000/api/slots?day=17&month=10&year=2026`

## Что работает

- при открытии страницы показывается «Загрузка…», затем календарь открывается на месяце, который вернул сервер, и сразу загружаются слоты выбранного дня;
- при клике по дню показывается «Загрузка слотов…», после ответа отрисовываются слоты, а выбранное время сбрасывается;
- кнопки «‹» и «›» листают месяцы и загружают слоты первого доступного дня;
- прошедшие дни приглушены и недоступны;
- занятые слоты зачёркнуты, полностью занятый день показывает сообщение об отсутствии мест;
- нижняя панель показывает день недели, число, месяц, год и выбранное время;
- при ошибке сервера вместо бесконечной загрузки показывается понятный текст и кнопка «Повторить»;
- при быстрых кликах по дням применяется ответ только на актуальную дату — неактуальные запросы отменяются через `AbortController`, а ответы дополнительно сверяются с выбранной датой;
- состояние загрузки и ошибки хранится отдельно для «сегодня» и для слотов.

## Проверка ошибок

Сценарии ошибки включаются параметром в адресной строке:

- `http://localhost:3000/?fail=1` — ошибка обоих запросов;
- `http://localhost:3000/?fail=today` — ошибка запроса «сегодня»;
- `http://localhost:3000/?fail=slots` — ошибка запроса слотов.

При `?fail=slots` календарь загружается, а на месте слотов появляется сообщение и кнопка «Повторить» — она повторяет запрос. Для сценария без ошибки откройте страницу без параметра.

Задержку ответа можно изменить константой `DELAY_MS` в `server/server.js`, а данные — в `server/database.js`.
