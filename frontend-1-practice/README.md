# Лезвие — выбор даты и времени

Практическая работа по вёрстке: страница «Выбор даты и времени» для пути записи в барбершоп.

## Что внутри

- `index.html` — семантическая разметка страницы;
- `styles.css` — все стили, адаптивность и состояния интерактивных элементов;
- `images/` — папка для изображений (в текущей версии страница собрана без растровых картинок, иконки встроены SVG).

## Как открыть

1. Откройте `index.html` двойным кликом — страница откроется в браузере.
2. Или запустите Live Server в VS Code: правый клик по `index.html` → **Open with Live Server**.

## Что реализовано

- шапка, основная часть и подвал на семантических тегах `<header>`, `<main>`, `<footer>`;
- этапы записи, карточка выбранной услуги и мастера;
- календарь на ноябрь 2026 с недоступными прошедшими днями и полностью занятой датой;
- выбор даты и времени без JavaScript — на радиокнопках, поэтому состояние выбора работает с клавиатуры;
- занятые слоты визуально отличаются штриховкой и зачёркнутым временем;
- `:hover` и `:focus-visible` для ссылок, кнопок, дат и слотов, `cursor: pointer` на кликабельных элементах;
- адаптивная вёрстка для планшетов и телефонов.
